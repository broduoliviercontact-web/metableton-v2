Tu en as marre des boutons virtuels ? Voici comment construire ton propre contrôleur physique pour Ableton Live, même si tu n'as jamais touché un fer à souder.

## Pourquoi faire soi-même un contrôleur MIDI ?

Tu passes tes journées à tordre des knobs virtuels avec ta souris. C'est précis, certes, mais c'est lent, peu intuitif, et surtout — ça ne sonne pas 'live'. Un contrôleur physique, c'est du hardware : tu touches, tu entends, tu réagis. C'est une autre relation à la musique.

Le problème, c'est le prix. Un contrôleur MIDI neuf, c'est facilement 80€, 150€, 300€. Pour un bout de plastique avec huit potentiomètres et quelques boutons, ça pique.

Alors voici la bonne nouvelle : tu peux construire le tien pour moins de 15€ de matériel, sans expertise en électronique, avec du code si simple qu'un enfant de 12 ans pourrait le comprendre.

<blockquote class="article-quote">
Pas de bluff. Pas de bidouille obscur. Juste un microcontrôleur, quelques composants basiques, et une librairie qui fait tout le travail technique pour toi.
</blockquote>

## Ce qu'il faut savoir avant de commencer

## Ton niveau

Tu n'as pas besoin d'être ingénieur. Si tu sais brancher un câble USB, lire un diagramme simple, et copier-coller du code dans un logiciel — alors tu as déjà le niveau requis.

## Ton budget

• ~10€ : Contrôleur de base (4-8 pots + boutons)
• 10-15€ : Version complète avec boîtier
• 20-30€ : Avec LEDs, écran OLED, finition pro

## Ton temps

- Premier montage : 30 minutes sur breadboard (pas de soudure)
- Premier contrôleur fonctionnel : 1-2 heures
- Version finie dans un boîtier : une demi-journée

<strong>Pièges à éviter</strong>

## La solution recommandée : Arduino Pro Micro + Control Surface

## L'Arduino Pro Micro (ATmega32U4)

Ce n'est pas le plus connu des Arduino, mais c'est le plus pratique pour le MIDI : USB-MIDI natif (pas besoin de logiciel intermédiaire), plug & play avec Ableton Live, petit format idéal pour intégrer dans un boîtier custom, et prix ridicule (3-5€ le clone).

## La librairie Control Surface (par tttapa)

C'est le cœur magique de l'opération. Une librairie Arduino qui gère tout le protocole MIDI pour toi. Syntaxe ultra-simple : 1 ligne pour déclarer un potentiomètre, 1 ligne pour dire qu'il envoie du MIDI CC, 1 ligne pour l'initialiser.

## La liste du matériel exact

- Arduino Pro Micro (ATmega32U4) clone : 3-5€
- Potentiomètres linéaires 10kΩ x8 : 1-2€
- Boutons poussoirs + capuchons x8 : 1-2€
- Breadboard 400 points : 1-2€
- Câbles jumper mâle-mâle x20+ : ~1€
- TOTAL : ~7-12€

## Le code : 5 lignes = 1 pot MIDI

Voici à quoi ressemble le code pour un contrôleur avec 1 potentiomètre qui contrôle un paramètre MIDI :

```js
#include <Control_Surface.h>

CCPotentiometer potentiometer(A0, MIDI_CC::Modulation_Wheel_1);

void setup() { Control_Surface.begin(); }
void loop()  { Control_Surface.loop(); }
```

C'est tout. Tu uploades ce code, tu branches un potentiomètre sur A0, tu tournes le bouton, et Ableton reçoit du MIDI.

## Un contrôleur complet : 8 potentiomètres + 8 boutons

Pour aller plus loin, voici le code complet d'un contrôleur 8x8 avec multiplexer 74HC4051 :

```js
#include <Control_Surface.h>

// Multiplexer 74HC4051
CD74HC4051 mux { A0, {3, 4, 5} };

// 8 potentiomètres MIDI (CC 1-8)
CCPotentiometer potentiometers[] {
  { mux.pin(0), {MIDI_CC::Modulation_Wheel_1, CHANNEL_1} },
  { mux.pin(1), {MIDI_CC::Breath_Controller, CHANNEL_1} },
  { mux.pin(2), {MIDI_CC::Foot_Controller, CHANNEL_1} },
  { mux.pin(3), {MIDI_CC::Portamento_Time, CHANNEL_1} },
  { mux.pin(4), {MIDI_CC::Data_Entry_MSB, CHANNEL_1} },
  { mux.pin(5), {MIDI_CC::Channel_Volume, CHANNEL_1} },
  { mux.pin(6), {MIDI_CC::Balance, CHANNEL_1} },
  { mux.pin(7), {MIDI_CC::Pan, CHANNEL_1} },
};

// 8 boutons MIDI (Notes 36-43)
NoteButton buttons[] {
  { 6,  {MIDI_Notes::C_2,  CHANNEL_1} },
  { 7,  {MIDI_Notes::Db_2, CHANNEL_1} },
  { 8,  {MIDI_Notes::D_2,  CHANNEL_1} },
  { 9,  {MIDI_Notes::Eb_2, CHANNEL_1} },
  { 10, {MIDI_Notes::E_2,  CHANNEL_1} },
  { 14, {MIDI_Notes::F_2,  CHANNEL_1} },
  { 15, {MIDI_Notes::Gb_2, CHANNEL_1} },
  { 16, {MIDI_Notes::G_2,  CHANNEL_1} },
};

void setup() {
  Control_Surface.begin();
}

void loop() {
  Control_Surface.loop();
}
```

## Alternatives rapides

• Raspberry Pi Pico (~9-13€) : plus de puissance, plus de GPIO, Bluetooth LE possible. Même library Control Surface.
• Arduino Nano + Hairless (~7-10€) : moins cher mais nécessite un pont logiciel. Moins plug & play.

## Prochaines étapes

- Imprimer un boîtier 3D (fichier STL ~2-5€ de filament)
- Ajouter des LEDs pour le feedback visuel
- Intégrer un écran OLED pour afficher les noms de paramètres
- Passer au Bluetooth LE avec un Raspberry Pi Pico W
- Créer des mappings MIDI personnalisés pour tes projets
