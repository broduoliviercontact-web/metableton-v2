Il fallait forcement que quelqu'un le fasse. **DOOM** tourne maintenant dans Ableton Live via une extension SDK.

Cette extension lance la version **Shareware de DOOM (1993)**, entiere et hors ligne, dans une fenetre d'extension a l'interieur de Live. Aucun interet productif direct. Un interet culturel immense.

## Pourquoi c'est plus qu'une blague

Le vieux test "can it run Doom?" devient ici une preuve de capacite pour l'ecosysteme Extensions. Si Live peut embarquer ce type d'interface et gerer ce niveau d'interaction, on comprend tout de suite que le SDK ne se limite pas a trois boites de dialogue CRUD.

Cela ouvre des pistes beaucoup plus larges : outils visuels, jeux musicaux, interfaces pedagogiques, experiences generatives ou petits environnements creatifs contextuels.

## Comment le lancer

1. Fais clic droit sur une **piste audio**, **piste MIDI** ou **scene**
2. Choisis **Doom: Play Doom**
3. Clique dans la fenetre pour capter le clavier
4. Joue avec les fleches ou **WASD**

## Verdict METABLETON

Clairement un manifeste plus qu'un outil. Mais un manifeste tres efficace pour montrer la souplesse de cette nouvelle couche de Live.
