# MLR Grid Slicer : découpe en slices colorés façon Monome

MLR Grid Slicer reprend l'esprit du célèbre Monome MLR et le transpose directement dans la Session View d'Ableton. Tu prends un clip audio, tu choisis un nombre de slices, et l'extension génère automatiquement une rangée de clips colorés, prêts à être déclenchés.

## Pourquoi c'est utile

C'est l'outil idéal pour le live looping et le beat slicing sans quitter la Session View. Au lieu de passer par le Simpler ou de couper manuellement dans l'écran Sample, tu obtiens des clips indépendants, chacun avec sa couleur, répartis sur les scènes. Le résultat est immédiatement jouable avec les follow actions pour créer des enchaînements aléatoires ou ordonnés. Cela ouvre des possibilités de performance directe que le slicing classique de Live ne propose pas nativement.

## Comment l'utiliser

1. Fais un clic droit sur un clip audio dans l'Arrangement ou la Session View.
2. Sélectionne Extensions → MLR Grid Slicer → Slice Cross Grid.
3. Règle les paramètres :
   - Nombre de slices : définit en combien de segments le clip sera découpé (de 2 à 64 selon le besoin).
   - Loop to slice : chaque slice boucle uniquement sur son propre segment.
   - Loop to end : chaque slice joue depuis son point de départ jusqu'à la fin du clip original.
4. Valide, et l'extension crée les clips colorés dans la Session View, alignés sur les scènes disponibles.
5. Active les follow actions sur les clips générés pour enchaîner les slices de manière programmée ou aléatoire.

Entre le slicing classique et ce workflow orienté clip, c'est une approche différente qui gagne à être connue. Pour les sets live ou les sessions d'improvisation, c'est un gain de temps énorme.
