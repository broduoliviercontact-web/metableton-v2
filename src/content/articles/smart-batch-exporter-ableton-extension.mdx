# Smart Batch Exporter : exporte tous les clips d'une piste en un clic

Smart Batch Exporter fait exactement ce que son nom promet : il prend tous les clips audio d'une piste dans l'Arrangement et les exporte d'un seul coup dans le dossier Samples/Imported/ du projet. C'est l'outil de finition idéal après une session de découpe, notamment après avoir utilisé Strip Silence ou BBenCut.

## Pourquoi c'est utile

Quand tu découpes un enregistrement en dizaines de clips, exporter chacun manuellement est une perte de temps. Cette extension automatise l'opération en un clic droit. Les fichiers exportés sont nommés de manière cohérente et rangés directement dans le projet, prêts à être réutilisés dans d'autres sets ou à constituer un pack de samples. C'est particulièrement pertinent dans les workflows de found sounds, où tu enregistres, découpes et exportes rapidement.

## Comment l'utiliser

1. Sauvegarde ton projet Live. L'extension refuse de fonctionner si le projet n'est pas enregistré, pour éviter les exports vers des chemins temporaires.
2. Sélectionne les clips audio sur la piste que tu veux exporter.
3. Fais un clic droit, puis Extensions → Smart Batch Exporter → Export to Folder.
4. Les clips sont exportés individuellement dans Samples/Imported/ avec un nommage automatique basé sur le nom du clip et l'index.
5. Retrouve les fichiers dans le navigateur de Live, directement accessibles pour les glisser dans d'autres projets.
