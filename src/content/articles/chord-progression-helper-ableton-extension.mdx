**Chord Progression Helper** propose un vrai outil d'ecriture harmonique dans Live. Tu choisis une tonalite, un mode de construction, tu cliques sur les accords qui t'interessent, et l'extension genere un **clip MIDI** avec la progression.

Le README mentionne deux logiques : une grille plutot fonctionnelle pour les progressions classiques et une approche plus sombre, chromatique, orientee mineur et couleurs empruntees.

## Pourquoi c'est interessant

Beaucoup d'outils MIDI generatifs balancent des resultats spectaculaires mais peu lisibles. Ici, on reste dans une approche plus pedagogique : tu vois les fonctions harmoniques, tu construis ta suite, puis tu l'ecris dans Live.

Pour quelqu'un qui veut gagner du temps sans perdre la main sur l'harmonie, c'est une proposition tres saine.

## Comment l'utiliser

1. Fais clic droit sur une **piste MIDI**
2. Lance **Create Chord Progression...**
3. Choisis une **tonalite**
4. Clique les accords pour les empiler dans la file
5. Ecris le resultat dans un clip MIDI

Chaque accord est ecrit sur une mesure, avec un voicing simple. C'est parfait pour esquisser une base avant de retravailler rythme, renversements ou orchestration.

## Verdict METABLETON

Une des extensions les plus utiles pour sortir rapidement d'une page blanche harmonique, surtout si tu veux rester dans un cadre comprehensible au lieu d'un random total.
