**Auralizer** est un effet gratuit signe **JB Project Studio**. D'apres Bedroom Producers Blog, Processeur d'image stéréo basé sur la Transformée de Hilbert. Phase-rotation du signal mid de 90° injecté dans le side. Contrôles : 3D Aura, 3D Focus (Standard 0-3ms / Extend jusqu'à 15ms), Wide, filtres high/low-pass. Mono-compatible.

## Pourquoi le regarder

tuto 'Comprendre le stereo image avec un plugin gratuit'. angle IA-vibe-coded (JUCE + AI pour UI) mais ancré dans l'ingénierie audio. Au lieu de l'installer juste parce qu'il est gratuit, le bon reflexe est de le tester sur une session precise : une basse, un bus drums, une texture, ou un probleme de mix clairement identifie.

## Formats et compatibilite

- **Format** : AU | VST3
- **Plateforme** : cross-platform
- **Statut** : free
- **Conditions** : Gratuit

## Limites a noter

macOS + Windows + Linux. Développé avec JUCE. IA utilisée pour UI design et drafting.

## Idee d'essai rapide

Charge Auralizer sur une piste simple, compare le signal avec et sans traitement, puis garde seulement un preset ou un reglage qui resout un probleme concret. Si l'outil ne change pas ton workflow en cinq minutes, archive-le plutot que d'alourdir ton dossier plugins.
