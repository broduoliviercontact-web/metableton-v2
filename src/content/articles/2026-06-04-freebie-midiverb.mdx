Un freebie balance sans explication finit souvent dans un dossier de telechargements oublie. Une bonne fiche donne envie de tester tout de suite.

## Les informations utiles

Pour chaque ressource, METABLETON devrait afficher :

- ce que c'est ;
- pourquoi c'est interessant ;
- avec quel systeme ou DAW c'est compatible ;
- comment l'installer ;
- une idee d'usage musical.

## Le format agent-friendly

Un agent peut tres bien transformer une veille en fiche publiee :

1. verifier la source ;
2. resumer l'interet musical ;
3. ajouter une capture ou un visuel ;
4. classer dans `freebies` ;
5. proposer un titre clair.

Le site se charge ensuite de rendre tout ca proprement.
