**Freesound Sampler** connecte directement **Freesound.org** a Live. Tu recherches un son, tu l'ecoutes, tu le telecharges, puis tu l'importes dans ta piste sans sortir du Set.

Il faut une cle API Freesound, mais une fois renseignee, l'extension la conserve pour les sessions suivantes. Les fichiers deja telecharges sont aussi remis en cache localement.

## Pourquoi c'est une bonne demo du SDK

Cette extension montre une autre facette des Ableton Extensions : la connexion a des **services externes**. Ici, on n'est plus dans le pur traitement local du Set, mais dans un workflow hybride entre navigation, preview audio, telechargement et placement automatique.

Le resultat est tres concret pour la prod quotidienne : chercher un one-shot, une texture ou un field recording sans casser le momentum.

## Comment l'utiliser

1. Cree une cle API gratuite sur Freesound
2. Fais clic droit sur une **piste audio**
3. Lance **Find samples**
4. Entre une recherche et ecoute les resultats
5. Clique sur un son pour l'importer

Le README precise que les fichiers importes sont des **previews MP3 128 kbps**. Donc c'est parfait pour tester, composer, decouper, ou sampler, mais pas forcement pour un usage final sans remplacement.

## Verdict METABLETON

Une des extensions les plus concretes pour la production de tous les jours. Si le SDK veut convaincre au-dela du simple effet nouveaute, c'est ce type d'outil qu'il faudra multiplier.
