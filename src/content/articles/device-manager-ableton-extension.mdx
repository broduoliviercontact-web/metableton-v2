# Device Manager : contrôle global de tous les devices du set

Dans un set complexe avec des dizaines de pistes, retrouver toutes les instances d'un même device devient vite un casse-tête. Device Manager apporte une vue d'ensemble simple et efficace : un dialogue de recherche qui liste tous les devices présents dans le projet, avec la possibilité de les activer, désactiver ou supprimer en masse.

## Pourquoi c'est utile

C'est l'outil qu'on aurait aimé avoir natif dans Live depuis longtemps. Quand tu travailles sur un gros set, tu te retrouves souvent avec des réverbes, des EQ ou des compresseurs répartis sur quinze pistes différentes. Si tu veux désactiver tous les Pro-Q 4 pour tester un mix sans traitement, ou supprimer tous les instances d'un plugin qui plante, Device Manager le fait en quelques secondes. Le search intégré filtre instantanément la liste, ce qui évite de scroller dans un projet dense.

## Comment l'utiliser

1. Fais un clic droit sur le header d'une piste.
2. Sélectionne Extensions → Device Manager.
3. L'interface s'ouvre avec une liste de tous les devices présents dans le set :
   - Recherche : tape le nom d'un device pour filtrer la liste en temps réel.
   - Toggle : active ou désactive toutes les instances d'un device d'un clic.
   - Delete : supprime en masse toutes les occurrences du device dans tout le projet.
4. Les changements s'appliquent immédiatement, sans besoin de redémarrer Live.

## Verdict METABLETON

Device Manager est une extension utilitaire discrète mais redoutablement efficace. Elle résout un problème quotidien dans les gros sets : la gestion dispersée des devices. La possibilité de désactiver ou supprimer en masse transforme une opération qui pouvait prendre plusieurs minutes en une action de deux clics. Pour les producteurs qui travaillent sur des projets orchestraux, des livesets ou des templates complexes, c'est un gain de temps et de clarté immédiat.
